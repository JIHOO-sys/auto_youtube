     <저장소>     = 2번에서 정한 저장소 이름
     <채널이름>   = 내 유튜브 채널 이름
     <이메일>     = 채널용 구글 계정 이메일

=====================================================================
 2단계. 구글 클라우드 (업로드 권한 + TTS 음성)
=====================================================================
※ 전부 "채널 계정"으로 로그인한 상태에서 합니다. 오른쪽 위 프로필을 꼭 확인하세요.

[2-1] 프로젝트 만들기
  1. console.cloud.google.com 접속 (처음이면 약관 동의)
  2. 맨 위 프로젝트 선택 상자 → [새 프로젝트] → 이름 youtube-shorts → [만들기]
  3. 맨 위에 youtube-shorts 가 선택돼 있는지 확인

[2-2] 결제 계정 연결 (TTS 가 요구함. 무료 한도 안에서는 0원)
  1. 왼쪽 메뉴 ☰ → [결제] → 결제 계정 연결 / 만들기 → 카드 등록
     (무료 체험 크레딧이 같이 생겨도 상관없음)
  2. [결제] → [예산 및 알림] → [예산 만들기]
       금액 1,000원 / 알림 기준 50%, 90%, 100% / 이메일 받기 → 저장
     ※ 예산은 "알림"만 보냅니다. 실제로 요금을 막는 건 코드 안의 안전장치(영상당 나레이션 700자 상한).
        하루 9개 × 700자 × 31일 ≈ 20만 자 = 무료 한도(100만 자)의 20% 이하.

[2-3] API 3개 켜기
  왼쪽 ☰ → [API 및 서비스] → [라이브러리] 에서 하나씩 검색해 [사용] 클릭
    - YouTube Data API v3
    - Google Drive API
    - Cloud Text-to-Speech API

[2-4] TTS 용 API 키
  1. [API 및 서비스] → [사용자 인증 정보] → [+ 사용자 인증 정보 만들기] → [API 키]
  2. 만들어진 키 이름 클릭 → [API 제한사항] → [키 제한] → Cloud Text-to-Speech API 만 체크 → [저장]
  3. [키 표시] 로 값 복사 → 메모장에 "GOOGLE_TTS_KEY=복사한값" 으로 적어 둠

[2-5] OAuth 동의 화면
  1. [API 및 서비스] → [OAuth 동의 화면] (화면에 따라 "Google 인증 플랫폼" → [시작하기])
  2. 앱 이름 shorts-uploader / 사용자 지원 이메일 <이메일> / 대상 [외부] / 연락처 <이메일> → 만들기
  3. [데이터 액세스](또는 범위) → [범위 추가 또는 삭제] → 아래 두 개를 "직접 입력" 칸에 넣고 [테이블에 추가] → 저장
       https://www.googleapis.com/auth/youtube
       https://www.googleapis.com/auth/drive
  4. [대상](또는 테스트 사용자) → [+ Add users] → <이메일> 추가
  5. 홈페이지 / 개인정보처리방침 주소는 6단계에서 만든 뒤 [브랜딩] 화면에 넣습니다.
  6. ★ [대상] → 게시 상태 [앱 게시] → 프로덕션 으로 바꾸기
     "테스트" 상태로 두면 7일마다 토큰이 만료되어 업로드가 멈춥니다.
     "확인되지 않은 앱" 경고가 떠도 내 계정은 그대로 쓸 수 있습니다 (검증 신청 안 해도 됨).

[2-6] OAuth 클라이언트 만들기
  1. [사용자 인증 정보] → [+ 사용자 인증 정보 만들기] → [OAuth 클라이언트 ID]
  2. 애플리케이션 유형: 웹 애플리케이션
     승인된 리디렉션 URI → [+ URI 추가] → https://developers.google.com/oauthplayground
  3. [만들기] → 나온 값을 메모장에 적어 둠
       YT_CLIENT_ID=클라이언트 ID
       YT_CLIENT_SECRET=클라이언트 보안 비밀번호

[2-7] 리프레시 토큰 발급 (가장 많이 틀리는 단계, 순서 그대로)
  1. developers.google.com/oauthplayground 접속
  2. 오른쪽 위 톱니바퀴 ⚙ → [Use your own OAuth credentials] 체크
     → OAuth Client ID / Client secret 에 2-6 값 붙여 넣기 → 창 닫기
     ※ 이걸 빼먹으면 나중에 unauthorized_client 오류가 납니다.
  3. 왼쪽 Step 1 아래 입력칸("Input your own scopes")에 아래 한 줄을 그대로 붙여 넣기
       https://www.googleapis.com/auth/youtube https://www.googleapis.com/auth/drive
     → [Authorize APIs]
  4. 채널 계정 선택 → "Google에서 확인하지 않은 앱" → [고급] → [shorts-uploader(으)로 이동] → 모두 [허용]
  5. Step 2 화면 → [Exchange authorization code for tokens]
  6. 나온 Refresh token 값을 메모장에 "YT_REFRESH_TOKEN=값" 으로 적어 둠

  [브랜드 채널일 때만] (개인 계정 아래 별도로 만든 "브랜드 계정" 채널)
    브랜드 채널은 드라이브가 없으므로 토큰을 2개 받습니다. 3번 입력칸만 다르게 해서 2-7을 두 번 합니다.
      ① https://www.googleapis.com/auth/youtube 만 → 4번 계정 고르는 화면에서 "브랜드 채널" 선택
         → YT_REFRESH_TOKEN
      ② https://www.googleapis.com/auth/drive 만 → "개인 계정" 선택
         → DRIVE_REFRESH_TOKEN
    이 경우 3단계 드라이브 폴더는 개인 계정 드라이브에 만듭니다.

★ 메모장에 적은 값(키·토큰)은 절대 채팅·코드·스크린샷에 올리지 마세요. 5단계 환경 변수에만 넣습니다.

 5단계. Claude 클라우드 환경 설정
=====================================================================
1. claude.ai/code → 새 세션 화면에서 저장소 <아이디>/<저장소> 선택
2. 환경(구름 아이콘) 옆 [⋯] 또는 [Edit] → 환경 설정 열기
3. Environment variables 칸에 메모장 값을 한 줄에 하나씩 붙여 넣기
     YT_CLIENT_ID=...
     YT_CLIENT_SECRET=...
     YT_REFRESH_TOKEN=...
     GOOGLE_TTS_KEY=...
     DRIVE_REFRESH_TOKEN=...      ← 브랜드 채널일 때만
4. Network access → "Custom"(사용자 지정) 선택, "Allow package managers" 는 체크 유지
   Allowed domains 에 아래를 한 줄씩 추가
     googleapis.com
     *.googleapis.com
     raw.githubusercontent.com
     youtube.com
     *.youtube.com
     *.ytimg.com
     huggingface.co
     *.huggingface.co
     *.hf.co
5. [저장]
   ※ 환경 변수를 바꾼 뒤에는 "새 세션"부터 적용됩니다. 열려 있던 세션에는 반영되지 않습니다.

증상 / 알림 내용                      원인 → 해결
-------------------------------------------------------------------------------
invalid_grant                         토큰 만료(동의 화면이 "테스트" 상태)
                                      → 2-5 ⑥ 프로덕션 게시 → 2-7 다시 발급 → 5단계 YT_REFRESH_TOKEN 교체 → 새 세션
unauthorized_client                   2-7 ② 톱니바퀴 설정을 빼먹고 토큰을 받음 → 2-7 처음부터 다시
insufficient permissions / 403        2-7 ③ 범위 한 줄을 빠뜨림 → 두 개 다 넣고 다시 발급
(드라이브 관련)
"missing env: ..."                    5단계 환경 변수 이름 오타·누락 → 고치고 새 세션
"롱폼원본 폴더에 새 영상이 필요해요"  원본을 다 씀 → 9단계
youtube id not found - skip           파일 이름이 바뀜 → 파일 이름 끝에 [유튜브ID 11자리] 붙이기
자막 생성 실패                        *.hf.co 미허용 → 5단계 ④ 확인 (자막 없이도 진행은 됨)
uploadLimitExceeded / quotaExceeded   유튜브 하루 한도 → 다음 날 자동 회복
루틴이 안 돌았음                      Pro 하루 5회 초과 / 루틴 꺼짐 → Routines 화면 확인
연결 거부 / 403 (네트워크)            5단계 ④ 허용 목록에 해당 주소 추가 → 새 세션
TTS 오류 (PERMISSION_DENIED 등)       2-3 TTS API 미사용 / 2-2 결제 계정 미연결 / 2-4 키 제한 확인
