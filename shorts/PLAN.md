# 돌뚜뿌꾸 - 롱폼 CC 영상 리뷰 쇼츠 루틴

## 컨셉 (두 가지를 같이 운영)
크리에이티브 커먼즈(CC BY) 롱폼 영상을 쇼츠로. 분야: K-POP·POP·JPOP, 연예계·연예인 활동, 브이로그,
외국 이야기, 로블록스, 생활꿀팁, 예능·코미디(코빅·1박2일 같은 개그 프로그램),
동물(강아지·고양이 등 반려동물). (치이카와·치어리더·룩북 제외)
- **A. 리뷰** (40~55초): 처음 TTS 훅 → 원본 장면들(출연자 목소리) → 마지막 TTS 마무리
- **B. 하루한픽** (15~30초, TTS 없음): 하이라이트 장면을 먼저 살짝 → 그 장면까지의 흐름 → 펀치라인.
  흰 화면 위 영상 + 상단 제목 + 하단 한 줄 코멘트 + 출처. 세로(폰 촬영) 원본이면 자동으로 전체 화면 + 상단 흰 제목 띠 + 초록 코멘트. 웃긴 순간·리액션·반전이 있는 원본(특히 예능)에 맞음
- 한 번 실행에 3개: **A 2개 + B 1개**. B에 맞는 웃긴 장면이 없으면 A 3개
- 배경음악 없음 (두 컨셉 모두)
- 방송사 예능(1박2일·코빅 등)은 대부분 CC가 아님 → 저작권자가 직접 CC로 올린 것만 사용
- **동물 원본**(강아지·고양이 등): A는 "동물 속마음 더빙"으로, B는 그대로 (아래 "동물 원본" 참고)

## 구성
- 계정: 채널 계정 (채널명 돌뚜뿌꾸), 환경 변수 YT_* / GOOGLE_TTS_KEY (브랜드 채널이면 DRIVE_REFRESH_TOKEN)
- 원본: 사용자가 채널 계정 드라이브 `롱폼원본` 폴더에 넣음. 파일명에 `[유튜브ID]` 권장 (예: `세븐틴 브이로그 [md5zNFKvfvE].mp4`).
  [유튜브ID]가 없으면 파일명(=영상 제목)으로 CC 영상을 찾아 매칭. 같은 이름의 .srt/.vtt 가 있으면 자막으로 씀. 없으면 faster-whisper 로 자동 생성 (`*.hf.co` 네트워크 허용 필요)
- 클라우드에서 YouTube 직접 다운로드는 봇 차단으로 불가 → 드라이브 경유
- `source.py` 원본 목록/가져오기 → `make.py` 쇼츠 생성 (원본 구간 + 원본 목소리 + 자막, A는 처음·끝 TTS) → `upload.py` 예약 공개
- 브랜딩: `channel/brand.py` (프로필, 배너. `shorts/intro.mp4` 는 만들어 두기만 하고 쇼츠에는 안 씀)
- 루틴: 06:40, 11:40, 17:40 KST에 제작 → 07:30, 12:30, 19:00에 3개씩 예약 공개
- 주간 원본 추천 루틴: 매주 월요일, 받을 CC 영상 목록을 알림으로 보냄

## 루틴 한 번 = 이렇게
0. `pip install -q faster-whisper` (자막 없는 원본용)
1. `python3 shorts/source.py list` → `n/3 made` 인 원본 중 하나 고름 (`done`·`skip` 제외). 원본 하나로 서로 다른 장면 쇼츠 최대 3개.
   쓸 원본이 없으면 만들지 말고 "롱폼원본에 새 영상 필요"라고 보고하고 끝낸다.
2. `python3 shorts/source.py fetch <drive_id> src/` → `src/meta.json`, `src/transcript.txt`(초 단위 시작시각 + 대사), `src/frames.jpg`(타임스탬프 24장)
   - **license 가 creativeCommon 이 아니면 그 원본은 쓰지 않는다.**
   - 업로더가 실제 저작권자인지 확인: 공식 소속사·방송사·본인 채널 OK. 영화·드라마·음방을 개인이 CC로 재업로드한 건 쓰지 않는다
   - `upload.py --recent` 에 같은 원본 ID로 이미 만든 쇼츠 제목이 있으면 그것과 다른 장면·다른 포인트로 쓴다
   - `src/moves.txt`: 2초마다 화면 움직임(0~100)·소리 크기 + 끝줄에 가장 활발한 20초 구간 3개. 대사가 적은 동물 원본에서 장면 찾는 데 쓴다
3. transcript.txt 와 frames.jpg(필요하면 해당 구간 프레임을 ffmpeg로 더 뽑아 직접 봄)를 보고 script.json 작성.
   **B. 하루한픽** script:
   ```json
   {"style": "pick", "title": "황제성이 무대에 *난입*한 이유", "comment": "화난 황제성이 제일 웃김ㅋㅋ",
    "credit": "출처 <원본 채널명>", "source": "src/video.mp4",
    "scenes": [{"orig": [하이라이트 시작, 끝], "lines": [...]}, {"orig": [...], "lines": [...]}]}
   ```
   - 첫 장면 = 펀치라인을 2~3초만 미리 보여줌(궁금증). 그다음 그 장면에 이르는 흐름을 원본 그대로 이어서 끝까지
   - say 금지(TTS 없음). 제목은 "~한 이유", "~의 결과" 처럼 궁금하게 20자 이내, 강조 *단어*는 분홍
   - comment 는 시청자 같은 한 줄 반응 (ㅋㅋ 허용), 15자 안팎
   - 합계 15~30초. 노래·무대 음악 구간 금지는 똑같이

   **A. 리뷰** script:
   ```json
   {"title": "상단 고정 제목 2줄, *강조*는 노란색", "source": "src/video.mp4",
    "scenes": [{"say": "훅", "src": [시작초]}, {"orig": ...}, {"orig": ...}, {"say": "마무리", "src": [시작초]}]}
   ```
   - 나레이션(say)은 **첫 장면과 마지막 장면에만** (make.py가 다른 위치면 거부). 가운데는 전부 원본 장면
     · 나레이션 장면 `{"say": "...", "src": [시작초, ...]}` : 리뷰어 목소리(TTS) + 원본 화면(소리 없음)
     · **원본 장면** `{"orig": [시작초, 끝초], "lines": [[시작초, "이름", "대사"], ...]}` : 출연자 목소리 그대로 + 줄별 자막. 3~15초
       시작초·대사는 transcript.txt 에서 그대로. 이름은 **성 빼고 두 글자**(도겸, 승관, 민규)로 분홍색 표시.
       이름은 원본 자막·대화 문맥(예: "[사진을 찍는 민규]", 본인 호칭)으로 **확실할 때만**. 애매하면 "" (얼굴로 판단하지 않는다)
   - 구성(40~55초): 훅 나레이션(영상 요약, 흥미를 끄는 말) → 원본 장면 3~4개 → 마무리 나레이션 + 질문.
     **원본 장면 3개 이상** — 재미는 출연자 본인 목소리에서 나온다. 웃긴 말·반전·리액션 순간을 transcript에서 고른다
   - 원본 장면에 노래·무대 음악이 깔린 구간은 쓰지 않는다 (음원 신고). 말소리 구간만
   - 나레이션은 줄거리 요약 금지. **리액션하는 친구 말투**: 짧게 끊고, 감탄·질문·반전을 넣는다
     좋음: "근데 여기서 반전이에요." / "아니 이걸 본인이 말한다고요?" / "이 표정 좀 보세요."
     나쁨: "~했어요. ~했어요." 식 나열, "~할 정도였어요", 설명문
   - 해요체 유지(반말·은어 금지)지만 문장마다 감정이 있어야 함. 한 문장 25자 이내 권장
   - 첫 2초 훅: 결과/반전/질문을 먼저 ("민규가 갑자기 대기실에 나타난 이유, 아세요?")
   - 마지막: 시청자에게 질문 하나 ("여러분은 누구 편이에요?") — 댓글 유도
   - 나레이션 합계 150자 안팎 (상한 700자)
   **동물 원본** (강아지·고양이 등 - 대사가 거의 없음):
   - 장면 찾기: transcript 대신 frames.jpg·moves.txt 로 후보를 잡고, 그 구간 프레임을 ffmpeg 로 더 뽑아 직접 본다.
     좋은 순간: 넘어짐·미끄러짐, 깜짝 놀람, 애교·꾹꾹이, 간식 앞 반응, 주인과의 밀당, 기대와 다른 반전
   - **A → 동물 속마음 더빙**: script 에 `"dub": true` 를 넣으면 나레이션을 중간 장면에도 쓸 수 있고, 원본 동물 소리가 작게 깔린다.
     ```json
     {"title": "간식 *숨긴 곳* 들킨 강아지", "source": "src/video.mp4", "dub": true,
      "scenes": [{"say": "주인이 간식 숨기는 거, 다 봤거든요?", "src": [12]},
                 {"say": "여기도 아니고... *여기*도 아니고", "src": [20, 23]},
                 {"orig": [26, 31], "lines": []},
                 {"say": "찾았다. 이건 이제 제 거예요.", "src": [31]},
                 {"say": "여러분 집 댕댕이도 이래요?", "src": [40]}]}
     ```
     · 동물 1인칭 속마음 대사 (해요체, 짧게, 한 문장 20자 안팎). 주인 목소리나 짖는·우는 소리가 웃기면 그 구간은 `orig` 로 그대로
     · 첫 장면 훅, 마지막은 시청자 질문 - A와 같음. 나레이션 합계 250자 안팎 (상한 700자). 40~55초
     · 동물 이름은 원본 제목·설명·대화에 나올 때만 쓴다
   - **B 하루한픽**은 그대로: 웃긴 순간 하나를 미리 살짝 → 흐름 → 펀치라인. 원본 소리(동물 소리·주인 리액션) 그대로
   - 원본에 업로더가 깐 배경음악이 계속 나오면 그 구간은 쓰지 않는다 (음원 신고). 현장음 위주 원본만
   - 동물을 괴롭히거나 다치는 장면, 위험한 장면은 쓰지 않는다

4. `python3 shorts/make.py script.json -o short.mp4`
5. 제목(40자 이내, 인물·숫자·구체어)과 설명란 → `python3 shorts/upload.py short.mp4 --title ... --desc ... --publish-at <공개 시각>`
   설명란 형식 (해시태그 3개 미만이면 거부, `youtu.be/ID` 링크로 원본 사용 횟수를 셈 - 반드시 넣을 것):
   ```
   한 줄 요약 (이 영상에서 뭘 볼 수 있는지)

   ✅ 포인트 1
   ✅ 포인트 2
   ✅ 포인트 3

   📺 원본: <원본 제목> - <채널명>
   https://youtu.be/<유튜브ID>
   라이선스: 크리에이티브 커먼즈 저작자 표시(CC BY)

   #돌뚜뿌꾸 #<인물/그룹> #<분야> ... 8~12개 #shorts
   ```
   B 는 제목 앞에 "하루한픽 | " 을 붙이고 해시태그에 #하루한픽 추가.
   동물 원본이면 해시태그에 #강아지 또는 #고양이 #반려동물 #동물 추가
