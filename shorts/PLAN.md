# 돌뚜뿌꾸 - 동물 CC 영상 쇼츠 루틴

## 컨셉 (두 가지를 같이 운영)
크리에이티브 커먼즈(CC BY) **포유류 동물 롱폼 영상**을 쇼츠로. 강아지·고양이는 물론 토끼·햄스터·기니피그·고슴도치·페럿 같은 반려동물,
수달·카피바라·판다·레서판다·원숭이·코끼리 같은 동물원·보호구역 동물, 염소·양·말·소·돼지·알파카 같은 농장 동물까지 포유류면 모두 OK.
포유류가 아닌 동물(새·파충류·물고기·곤충 등)과 동물이 아닌 원본은 쓰지 않는다.
**한국·일본 채널 영상만** 쓴다 (한국어 더빙·자막과 어울림). 영어·스페인어·중국어 등 그 밖의 언어로 말하는 원본은 쓰지 않는다.
- **A. 속마음 더빙** (40~55초): 동물 1인칭 속마음 나레이션(TTS) + 원본 장면. 원본 현장음은 나레이션 밑에 작게 깔림.
  웃긴 소리(짖음·하악질·울음·주인·사육사 리액션)는 원본 장면 그대로
- **B. 하루한픽** (15~30초, TTS 없음): 웃긴 순간을 먼저 살짝 → 그 순간까지의 흐름 → 펀치라인.
  흰 화면 위 영상 + 상단 제목 + 하단 한 줄 코멘트 + 출처. 세로(폰 촬영) 원본이면 자동으로 전체 화면 + 상단 흰 제목 띠 + 초록 코멘트
- 한 번 실행에 3개: **A 2개 + B 1개**. B에 맞는 웃긴 순간이 없으면 A 3개
- 배경음악 없음 (두 컨셉 모두). 업로더가 깐 배경음악이 계속 나오는 구간은 쓰지 않는다 (음원 신고). 현장음 위주 원본만
- 동물을 괴롭히거나 다치는 장면, 위험한 장면, 아픈 동물을 웃음거리로 만드는 장면은 쓰지 않는다.
  야생 동물의 사냥·포식·짝짓기, 도축·사냥 영상, 야생 동물을 사람이 만지거나 먹이 주는 장면(위험 행동 조장)도 쓰지 않는다

## 구성
- 계정: 채널 계정 (채널명 돌뚜뿌꾸), 환경 변수 YT_* / GOOGLE_TTS_KEY (브랜드 채널이면 DRIVE_REFRESH_TOKEN)
- 원본: 사용자가 채널 계정 드라이브 `롱폼원본` 폴더에 넣음. 파일명에 `[유튜브ID]` 권장 (예: `간식 훔쳐먹은 강아지 [N9UJE7TMe1I].mp4`).
  [유튜브ID]가 없으면 파일명(=영상 제목)으로 CC 영상을 찾아 매칭. 같은 이름의 .srt/.vtt 가 있으면 자막으로 씀. 없으면 faster-whisper 로 자동 생성 (`*.hf.co` 네트워크 허용 필요)
- 클라우드에서 YouTube 직접 다운로드는 봇 차단으로 불가 → 드라이브 경유
- `source.py` 원본 목록/가져오기 → `make.py` 쇼츠 생성 (원본 구간 + 현장음 + 자막, A는 속마음 더빙 TTS) → `upload.py` 예약 공개
- 브랜딩: `channel/brand.py` (프로필, 배너. `shorts/intro.mp4` 는 만들어 두기만 하고 쇼츠에는 안 씀)
- 루틴: 06:40, 11:40, 17:40 KST에 제작 → 07:30, 12:30, 19:00에 3개씩 예약 공개
- 주간 원본 추천 루틴: 매주 월요일, 받을 동물 CC 영상 목록을 알림으로 보냄

## 루틴 한 번 = 이렇게
0. `pip install -q faster-whisper` (자막 없는 원본용)
1. `python3 shorts/source.py list` → `n/3 made` 인 원본 중 **제목으로 봐서 동물 영상인 것만** 하나 고름 (`done`·`skip` 제외).
   동물이 아닌 원본(K-POP·예능 등)과 한국·일본 채널이 아닌 원본(영어·스페인어 등 제목)은 건너뛴다. 원본 하나로 서로 다른 장면 쇼츠 최대 3개.
   쓸 동물 원본이 없으면 만들지 말고 "롱폼원본에 새 동물 영상 필요"라고 보고하고 끝낸다.
2. `python3 shorts/source.py fetch <drive_id> src/` → `src/meta.json`, `src/transcript.txt`(초 단위 시작시각 + 말소리),
   `src/frames.jpg`(타임스탬프 24장), `src/moves.txt`(2초마다 화면 움직임 0~100·소리 크기 + 끝줄에 가장 활발한 20초 구간 3개)
   - **license 가 creativeCommon 이 아니면 그 원본은 쓰지 않는다.**
   - 업로더가 실제 저작권자인지 확인: 직접 찍은 반려인·크리에이터·농장·동물원·보호구역 본인 채널만. 틱톡·인스타 영상 모음, "웃긴 동물 모음" 재업로드 채널은 쓰지 않는다
   - `upload.py --recent` 에 같은 원본 ID로 이미 만든 쇼츠 제목이 있으면 그것과 다른 장면·다른 포인트로 쓴다
3. 장면 찾기: 동물 영상은 대사가 적다. frames.jpg·moves.txt 로 후보 구간을 잡고, 그 구간 프레임을 ffmpeg 로 더 뽑아 직접 본다
   (예: `ffmpeg -ss 60 -i src/video.mp4 -t 60 -vf "fps=1/4,scale=480:-2,tile=3x5" -frames:v 1 p.jpg`).
   원본 화면에 박힌 업로더 자막·원본 설명란에서 상황과 동물 이름을 파악한다. transcript.txt 는 주인 말소리 확인용.
   일본 원본: transcript 는 일본어로 나온다. `orig` 장면 자막(lines)은 일본어 말을 **자연스러운 한국어로 옮겨** 쓴다 (원문 일본어 그대로 쓰지 않는다).
   동물 이름은 원본 표기를 한국어 발음으로 (さくら → 사쿠라). 설명란 원본 줄의 제목·채널명은 원문 그대로
   좋은 순간: 넘어짐·미끄러짐, 깜짝 놀람, 애교·꾹꾹이, 간식 앞 반응, 주인과의 밀당, 혼날 때 눈치, 기대와 다른 반전

   **A. 속마음 더빙** script:
   ```json
   {"title": "간식 훔쳐먹고\n*숨어버린* 강아지", "source": "src/video.mp4", "dub": true,
    "scenes": [{"say": "아침부터 간식 봉지가 *뜯겨* 있어요. 범인은 누굴까요?", "src": [20, 24]},
               {"say": "저요? 저는... 집에 있는데요?", "src": [46, 62]},
               {"orig": [84, 92], "lines": []},
               {"say": "엄마가 아무 말도 안 해요. 이게 더 *무서워요*.", "src": [128, 132]},
               {"orig": [164, 172], "lines": [[165.0, "", "이제 그만 먹어야 돼"]]},
               {"say": "뽀뽀 한 번이면 다 용서돼요. …내일 또 먹어도 되겠죠?", "src": [172]}]}
   ```
   - 나레이션 장면 `{"say": "...", "src": [시작초, ...]}` : 속마음 TTS + 그 구간 화면 + 현장음 작게. 시작초 여러 개면 컷을 나눠 보여줌
   - 원본 장면 `{"orig": [시작초, 끝초], "lines": [[시작초, "이름", "말"], ...]}` : 현장음 그대로 3~15초. 주인 말소리가 있으면 transcript 에서 그대로 자막으로.
     말하는 사람 이름은 확실할 때만, 아니면 "" (얼굴로 판단하지 않는다)
   - 구성(40~55초): 첫 장면 훅(상황·반전·질문) → 속마음 + 원본 장면 번갈아 → 마지막 한마디
   - **마지막 한마디**: 동물 1인칭으로, 그 영상 상황을 이어서 끝내는 능청·반전 한마디 (이야기의 마지막 대사처럼)
     좋음: "뽀뽀 한 번이면 다 용서돼요. …내일 또 먹어도 되겠죠?" / "다음엔 안 들키게 할게요. 아, 이건 비밀이에요" /
           "한 입만 더 주시면 오늘 착하게 있을게요" / "저 하나도 안 놀랐어요. 진짜예요"
     · 시청자에게 묻는 말은 3개 중 1개 정도만, 그것도 동물 말투로 ("제가 잘못한 거 맞아요? 댓글로 변호 좀 해주세요")
     · "여러분 집 ○○도 ~해요?" 같은 내레이터 질문은 쓰지 않는다. 같은 회차 3개끼리, 최근 업로드와도 같은 표현을 반복하지 않는다
   - 속마음 말투: 동물 1인칭, 해요체(반말·은어 금지), 짧게 끊고 감정·능청·반전. 한 문장 20자 안팎
     좋음: "저요? 저는... 집에 있는데요?" / "모르는 척... 모르는 척..." / "이건 이제 제 거예요."
     나쁨: 상황 설명문 ("강아지가 간식을 먹었어요"), "~했어요. ~했어요." 나열
   - 여러 마리가 나오면 누구 속마음인지 화면으로 분명할 때만 (그 동물이 화면 중심일 때)
   - 동물 이름은 원본 제목·설명·업로더 자막·대화에 나올 때만 쓴다
   - 나레이션 합계 250자 안팎 (상한 700자)

   **B. 하루한픽** script:
   ```json
   {"style": "pick", "title": "투명벽 앞에서 *멈춘* 고양이", "comment": "표정이 다 했다ㅋㅋ",
    "credit": "출처 <원본 채널명>", "source": "src/video.mp4",
    "scenes": [{"orig": [하이라이트 시작, 끝], "lines": []}, {"orig": [...], "lines": [...]}]}
   ```
   - 첫 장면 = 펀치라인을 2~3초만 미리 보여줌(궁금증). 그다음 그 순간에 이르는 흐름을 원본 그대로 이어서 끝까지
   - say 금지(TTS 없음). 원본 소리(동물 소리·주인 리액션) 그대로. 제목은 "~한 이유", "~의 결과" 처럼 궁금하게 20자 이내, 강조 *단어*는 분홍
   - comment 는 시청자 같은 한 줄 반응 (ㅋㅋ 허용), 15자 안팎
   - 합계 15~30초

4. `python3 shorts/make.py script.json -o short.mp4`
5. 제목(40자 이내, 동물 종류·이름·구체적 상황)과 설명란 → `python3 shorts/upload.py short.mp4 --title ... --desc ... --publish-at <공개 시각>`
   설명란 형식 (해시태그 3개 미만이면 거부, `youtu.be/ID` 링크로 원본 사용 횟수를 셈 - 반드시 넣을 것):
   ```
   한 줄 요약 (이 영상에서 뭘 볼 수 있는지)

   ✅ 포인트 1
   ✅ 포인트 2
   ✅ 포인트 3

   📺 원본: <원본 제목> - <채널명>
   https://youtu.be/<유튜브ID>
   라이선스: 크리에이티브 커먼즈 저작자 표시(CC BY)

   #돌뚜뿌꾸 #<동물 이름: 강아지·고양이·수달·카피바라 등> #동물 #귀여운동물 #<품종/종> ... 8~12개 #shorts (반려동물이면 #반려동물 추가)
   ```
   A 는 해시태그에 #동물더빙 (강아지·고양이면 #강아지더빙 / #고양이더빙) 추가. B 는 제목 앞에 "하루한픽 | " 을 붙이고 해시태그에 #하루한픽 추가
6. 업로드를 다 마치면 `python3 shorts/source.py clean` → 쇼츠 3개를 다 만든 원본(과 같은 이름의 자막)을 드라이브 휴지통으로 옮긴다 (30일 안에 복구 가능).
   "skip: Drive token is read-only" 가 나오면 지우지 못한 것이니 보고에 한 줄만 적는다 (실패 아님)
