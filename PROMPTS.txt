[P1 채널 이름·브랜딩 맞추기]   ← 매뉴얼 6단계, 처음 한 번
---------------------------------------------------------------------
이 저장소를 내 유튜브 채널용으로 맞춰줘. 채널 이름은 "<채널이름>", 문의 이메일은 <이메일>.
1. 아래 파일에서 기존 채널 이름과 이메일을 전부 내 것으로 바꿔:
   shorts/make.py 의 BRAND, shorts/PLAN.md (제목·해시태그), shorts/source.py 설명 주석,
   channel/brand.py (프로필·배너 글자), docs/index.html, docs/privacy.html
2. 배너 분야 문구는 shorts/PLAN.md "컨셉"의 분야와 맞춰.
3. 폰트를 먼저 받고 (python3 -c "import sys; sys.path.insert(0, 'shorts'); import make; make.font()")
   python3 channel/brand.py 로 channel/profile.png, channel/banner.png 를 다시 만들어서 나한테 보여줘.
4. main 브랜치에 커밋·푸시해줘. main 에 직접 푸시가 안 되면 PR 을 만들고 머지하는 방법을 알려줘.

[P2 동작 확인]   ← 매뉴얼 7단계
---------------------------------------------------------------------
main 브랜치에서 아래 세 가지를 실행해서 각각 성공/실패와 오류 원인을 한 줄씩 알려줘. 업로드나 수정은 하지 마.
1) cd shorts && python3 upload.py --recent        (유튜브 연결)
2) cd shorts && python3 source.py list             (드라이브 '롱폼원본' 연결)
3) cd shorts && python3 source.py suggest          (CC 영상 검색)
4) TTS 확인: cd shorts && python3 -c "import make; make.tts('테스트입니다', '/tmp/t.wav'); print('ok')"

[P3 루틴 만들기]   ← 매뉴얼 8단계, 처음 한 번
---------------------------------------------------------------------
지금 이 환경으로 루틴(예약 작업) 2개를 만들어줘. 둘 다 실행할 때마다 새 세션, 끝나면 휴대폰 알림.

루틴 1) 이름 "쇼츠 제작 (07:30·12:30·19:00 × 3개)", cron: CRON_TZ=Asia/Seoul 40 6,11,17 * * *
프롬프트는 아래 "=== 루틴1 시작 ===" 과 "=== 루틴1 끝 ===" 사이 그대로.

=== 루틴1 시작 ===
<채널이름> 유튜브 채널(동물 쇼츠 채널)에 포유류 동물 롱폼 CC 영상으로 쇼츠 3개(A 속마음 더빙형 2개 + B 하루한픽형 1개)를 만들어 예약 공개로 업로드해줘.
0. 공개 시각: `TZ=Asia/Seoul date` 로 지금 한국 시간을 보고 07:30 / 12:30 / 19:00 중 지금 이후 가장 가까운 시각을 PUBLISH_AT 으로 (예: 2026-10-15T07:30:00+09:00). 3개 모두 같은 시각.
1. 저장소 <아이디>/<저장소> 가 작업 폴더에 없으면 add_repo(owner <아이디>, repo <저장소>)로 추가해 clone. main 브랜치에서 shorts/PLAN.md 를 읽고 "컨셉"과 "루틴 한 번" 절차를 그대로 따른다.
2. 쇼츠 3개: A(속마음 더빙, "dub": true) 2개 + B(하루한픽, "style": "pick", TTS 없음) 1개. B에 맞는 웃긴 순간이 없으면 A 3개. 원본 하나에서 서로 다른 장면으로 여러 개 만들어도 되고(원본당 최대 3개), 원본이 모자라면 만들 수 있는 만큼만. 배경음악 없음.
   - 롱폼원본 폴더에서 포유류 동물(강아지·고양이·토끼·햄스터·수달·카피바라·판다·농장 동물 등) 영상만 쓴다. 새·파충류 등 포유류가 아닌 동물이나 K-POP·예능 등 동물이 아닌 원본은 건너뛴다.
   - license 가 creativeCommon 이 아니거나 업로더가 직접 찍은 사람(본인 채널)으로 보이지 않는 원본은 쓰지 않는다.
   - 각 쇼츠: script 작성 → make.py → upload.py --publish-at PUBLISH_AT (설명란에 원본 youtu.be 링크·채널명·CC BY 표기 필수).
   - 한 개가 실패해도 나머지는 계속.
3. 쓸 동물 원본이 하나도 없으면 아무것도 올리지 말고 "롱폼원본 폴더에 새 동물 영상이 필요해요" 한 줄만 보고.
4. 공개 예정 시각과 업로드된 URL·제목·컨셉(A/B)·사용한 원본을 개당 한 줄로 보고. 실패나 경고(자막 생성 실패, 배경음악 의심 등)가 있으면 원인 한 줄. 커밋/푸시는 하지 않는다.
=== 루틴1 끝 ===

루틴 2) 이름 "주간 원본 추천", cron: CRON_TZ=Asia/Seoul 47 8 * * 1
프롬프트는 아래 "=== 루틴2 시작 ===" 과 "=== 루틴2 끝 ===" 사이 그대로.

=== 루틴2 시작 ===
<채널이름> 유튜브 채널(동물 롱폼 CC 영상을 쇼츠로 만드는 채널: 속마음 더빙형 + 하루한픽형)을 위해, 이번 주에 사용자가 받아서 드라이브에 넣을 포유류 동물 원본 영상 10개를 추천해줘. 채널 주인이 직접 요청한 작업이고, 아래 저장소 스크립트 실행(읽기 전용 조회)을 허용했어.
1. 저장소 <아이디>/<저장소> 가 없으면 add_repo(owner <아이디>, repo <저장소>)로 추가하거나 git clone 한 뒤 main 브랜치에서 shorts/PLAN.md 를 읽는다.
2. `cd shorts && python3 source.py suggest` 를 실행한다. 이 명령은 채널 계정의 YouTube API 로 동물 CC 영상 후보를 검색어별로 조회만 한다 (업로드·수정 없음). 이미 쓴 원본과 드라이브에 받아둔 원본은 자동으로 빠져 있다.
3. 후보 중에서 고른다: 포유류 동물(강아지·고양이·토끼·햄스터·수달·카피바라·판다·농장 동물 등)이 주인공인 3분 이상 롱폼, 직접 찍은 반려인·크리에이터·농장·동물원·보호구역 본인 채널인 것만. 사냥·포식·도축 영상 제외. 틱톡·인스타 모음, "웃긴 동물 모음" 재업로드 채널, 동물이 주인공이 아닌 영상(사람 브이로그·게임 등), 구조·투병처럼 웃음거리로 쓰기 어려운 영상 제외. 웃긴 순간·리액션이 많은 것 위주로, 배경음악 없이 현장음 위주로 보이는 것 우선. 강아지·고양이 위주로 하되 다른 포유류도 2~3개 섞고, 한국어 채널 우선 (모자라면 외국 채널도 가능).
4. 이 형식으로만 보고:
   `1. [동물 종류] 제목 - 채널 (길이, 조회수) https://youtu.be/ID`
   그다음 한 줄로 10개 링크를 공백으로 이은 다운로드 명령:
   `yt-dlp -f "bv*[height<=1080][ext=mp4]+ba[ext=m4a]/b[ext=mp4]" --write-subs --sub-langs "ko,en,es" --convert-subs srt -P "%USERPROFILE%\Downloads\롱폼원본" <링크들>`
   마지막 줄: "받은 파일을 드라이브 '롱폼원본' 폴더에 넣어 주세요."
코드 수정·커밋·업로드는 하지 않는다.
=== 루틴2 끝 ===

다 만들면 두 루틴의 이름, 다음 실행 시각(한국 시간)을 알려줘.
