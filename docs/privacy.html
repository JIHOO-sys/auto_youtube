개인정보처리방침

시행일: 2026년 10월 15일

shorts-uploader(이하 "앱")는 유튜브 채널 돌뚜뿌꾸의 운영자가 본인 채널을 관리하기 위해 사용하는 개인용 도구입니다.

1. 사용하는 Google 사용자 데이터

  • YouTube (https://www.googleapis.com/auth/youtube): 운영자 본인 채널에 동영상을 업로드·예약하고, 최근 업로드 목록을 조회합니다.
  • Google Drive (https://www.googleapis.com/auth/drive.readonly): 운영자 본인 드라이브의 지정된 폴더에서 원본 영상 파일을 읽기 전용으로 가져옵니다.

2. 데이터 이용 목적과 범위

위 데이터는 운영자 본인 채널의 영상 제작과 업로드에만 사용합니다. 앱은 운영자 이외의 사용자 계정에 접근하지 않습니다.

3. 공유 및 판매

Google 사용자 데이터를 제3자에게 판매하거나 공유하지 않으며, 광고 목적으로 사용하지 않습니다.

4. 보관 및 삭제

인증 토큰은 운영자가 관리하는 실행 환경의 환경 변수에만 저장됩니다. 원본 영상은 작업 중에만 임시로 사용하고 작업 후 삭제합니다. 접근 권한은 언제든지 Google 계정 권한 페이지에서 철회할 수 있습니다.

5. Google API 서비스 사용자 데이터 정책 준수

앱이 Google API로부터 받은 정보의 사용 및 다른 앱으로의 전송은 제한된 사용 요구사항을 포함한 Google API 서비스 사용자 데이터 정책을 준수합니다.
